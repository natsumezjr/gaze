# 眼动追踪系统 - 主程序使用指南

## 🎯 概述

现在您可以直接运行 `recognition/main.py` 来实现 `workflow_summary.md` 中描述的完整眼动追踪工作流程！

## 🚀 快速启动

### 方式1: 一键启动 (推荐)
```bash
python run_gaze_tracking.py
```

### 方式2: 直接运行主程序
```bash
cd project/recognition
python main.py
```

## 📋 完整工作流程

### 1️⃣ **系统启动阶段**
```
启动程序 → 初始化摄像头 → 加载人脸检测器 → 开始视频循环
```

### 2️⃣ **粗拟合阶段** (检测到人脸后)
```
人脸检测 → 关键点提取 → 眼球形状拟合 → 初始化校准会话 → 等待收集校准点
```

### 3️⃣ **校准点收集阶段** (用户交互)
```
显示9点校准网格 → 用户点击校准点 → 收集校准样本 → 重复9次
```

### 4️⃣ **精细拟合阶段** (收集完9个点后)
```
重新眼球形状拟合 → Kappa校准 → 计算补偿视线 → 评估拟合质量
```

## 🎮 使用步骤

### 1. 启动系统
```bash
python run_gaze_tracking.py
```

### 2. 等待自动打开浏览器
- 系统会自动打开 http://localhost:5000
- 等待粗拟合完成（约10-30秒）

### 3. 开始校准
- 点击"开始校准"按钮
- 系统会显示9个校准点
- 依次注视每个校准点

### 4. 完成校准
- 系统自动进行Kappa校准
- 查看最终校准结果
- 开始实时眼动追踪

## 📊 API接口

### 系统状态
- `GET /api/status` - 获取系统状态

### 摄像头控制
- `POST /api/camera/start` - 启动摄像头

### 校准流程
- `POST /api/calibration/start` - 开始校准
- `POST /api/calibration/collect` - 收集校准点

### 注视点追踪
- `GET /api/gaze/current` - 获取当前注视点
- `POST /api/gaze/accuracy` - 检查注视准确度

## 🐛 故障排除

### 1. 摄像头无法启动
- 检查摄像头权限
- 确认摄像头未被其他程序占用
- 检查OpenCV安装

### 2. 人脸检测失败
- 确保光线充足
- 调整摄像头角度
- 检查MediaPipe安装

### 3. 校准精度低
- 确保用户注视校准点
- 检查瞳孔检测质量
- 调整校准参数

### 4. 前端连接失败
- 检查后端服务器状态
- 确认端口未被占用
- 检查CORS设置
