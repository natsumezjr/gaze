# 眼动校准系统 - 使用与测试指南

## 📋 系统概述

本系统是一个基于MediaPipe的眼动校准系统，采用注视触发机制，确保校准的真实性和准确性。

### 🎯 核心特性
- **真实注视触发**：只有在用户真正注视校准点时才触发校准动画
- **智能超时处理**：30秒超时机制，提供专业的问题诊断
- **实时注视反馈**：显示当前注视位置和准确度
- **6点六边形校准**：优化的校准点布局
- **专业错误处理**：区分不同类型的问题并提供解决方案

## 🔧 故障排除

### 常见问题及解决方案

#### 1. 后端无法启动
**症状**：运行`python backend_server.py`报错
**解决方案**：
```bash
# 安装依赖
pip install flask opencv-python mediapipe numpy

# 检查端口占用
netstat -an | findstr :5000

# 如有占用，杀死进程或换端口
```

#### 2. 摄像头无法访问
**症状**：页面显示"摄像头未激活"
**解决方案**：
- 检查摄像头权限
- 确认摄像头未被其他程序占用
- 重新插拔USB摄像头（如使用外接摄像头）

#### 3. 注视点检测不准确
**症状**：注视点位置偏移较大
**解决方案**：
- 调整坐姿，确保人脸正对摄像头
- 改善环境光线
- 调整屏幕亮度
- 重新进行校准

#### 4. 校准超时频繁
**症状**：经常出现30秒超时
**解决方案**：
- 检查人脸检测是否正常
- 确保眼部清晰可见
- 调整摄像头角度
- 检查环境光线是否充足

## 📊 性能指标

### 正常运行指标
- **注视检测延迟**：< 200ms
- **校准触发精度**：偏差 < 100px
- **连续准确注视**：3次 @ 150ms间隔
- **超时时长**：30秒
- **FPS范围**：5-15 fps
- **内存使用**：< 500MB

### 调试信息说明
- **注视坐标**：当前注视点的屏幕坐标
- **置信度**：注视检测的准确度百分比
- **准确度等级**：excellent > good > fair > poor
- **偏差距离**：注视点与目标点的像素距离
