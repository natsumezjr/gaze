# 眼动追踪系统工作流程总结

## 🚀 当前完整流程

### 1️⃣ **系统启动阶段**
```
启动程序 → 初始化摄像头 → 加载人脸检测器 → 开始视频循环
```

### 2️⃣ **粗拟合阶段** (检测到人脸后)
```
人脸检测 → 关键点提取 → 眼球形状拟合 → 初始化校准会话 → 等待收集校准点
```

**关键输出**:
- 眼球中心坐标
- 眼球半径
- 拟合置信度
- 会话初始化成功

### 3️⃣ **校准点收集阶段** (用户交互)
```
显示9点校准网格 → 用户按's'键 → 收集校准样本 → 重复9次
```

**9个校准点位置**:
```
(192, 108)  (960, 108)  (1728, 108)
(192, 540)  (960, 540)  (1728, 540)  ← 中心点
(192, 972)  (960, 972)  (1728, 972)
```

### 4️⃣ **精细拟合阶段** (收集完9个点后)
```
重新眼球形状拟合 → Kappa校准 → 计算补偿视线 → 评估拟合质量
```

**最终输出**:
- Kappa角度
- 拟合质量评估
- 补偿后的视线向量

## 📊 数据流图

```
摄像头视频
    ↓
人脸检测 (MediaPipe)
    ↓
关键点提取 (瞳孔、眼角等)
    ↓
数据管理器 (RECG_FIT_DATA_MANAGER)
    ↓
眼球形状拟合 (fit_all_eyes)
    ↓
会话管理器 (SESSION_MANAGER)
    ↓
校准样本收集 (push_sample)
    ↓
Kappa校准 (estimate_kappa_pro)
    ↓
最终视线计算 (compute_gaze)
```

## 🔧 关键模块说明

### 识别模块 (`project/recognition/`)
- **main.py**: 主程序，控制整个流程
- **detector.py**: 人脸检测器
- **landmark_extractor.py**: 关键点提取
- **camera_calibration.py**: 相机校准

### 拟合模块 (`project/fitting/`)
- **main.py**: 眼球形状拟合
- **kappa_calibrator_pro.py**: Kappa校准算法
- **gaze_estimator.py**: 视线计算
- **api.py**: 校准接口

### 数据管理 (`project/recg_fit_data/`)
- **data_manager.py**: 数据存储和管理
- **state.py**: 会话状态管理

## 🎯 用户操作步骤

1. **启动程序**
   ```bash
   python project/recognition/main.py
   ```

2. **等待粗拟合完成**
   - 确保人脸在摄像头视野内
   - 系统自动进行眼球形状拟合
   - 看到"眼球形状拟合完成"提示

3. **收集校准点**
   - 看到屏幕上的红点
   - 看向红点并按's'键
   - 重复9次，覆盖屏幕不同位置

4. **等待精细拟合完成**
   - 系统自动进行Kappa校准
   - 查看最终校准结果

## 🐛 常见问题解决

### 1. 粗拟合失败
**原因**: 人脸检测失败或关键点数据不足
**解决**: 调整光照、角度，确保人脸清晰可见

### 2. 校准样本收集失败
**原因**: 瞳孔数据获取失败
**解决**: 确保眼睛在摄像头视野内，按's'键时保持稳定

### 3. Kappa校准失败
**原因**: 校准样本数据质量不足
**解决**: 重新收集校准点，确保覆盖屏幕不同区域
