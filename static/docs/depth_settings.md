# 深度设置配置说明

## 概述

眼动追踪系统现在支持多种深度设置模式，不再局限于固定的0.6米深度。你可以根据实际使用场景选择合适的深度模式。

## 深度模式

### 1. 固定深度模式
使用预设的固定深度值，适合稳定的使用环境。

**可选值**:
- `near`: 0.4米 (近距离使用)
- `medium`: 0.8米 (中距离使用) 
- `far`: 1.2米 (远距离使用)
- `default`: 0.6米 (默认距离)

### 2. 自动深度模式
基于人脸检测动态估计深度，适合距离变化的使用场景。

**工作原理**:
- 检测人脸关键点
- 基于瞳孔间距估计距离
- 自动调整深度值

## 配置文件

### 位置
`project/recognition/config/depth_settings.json`

### 配置示例
```json
{
    "depth_mode": "auto",
    "fixed_depth_options": {
        "near": 0.4,
        "medium": 0.8,
        "far": 1.2,
        "default": 0.6
    },
    "auto_depth_settings": {
        "min_depth": 0.3,
        "max_depth": 2.0,
        "real_pupil_distance": 0.065,
        "fallback_depth": 0.6
    },
    "depth_camera_settings": {
        "enabled": false,
        "camera_index": 1,
        "depth_scale": 0.001
    }
}
```

### 配置参数说明

#### depth_mode
- **类型**: string
- **可选值**: `"auto"`, `"near"`, `"medium"`, `"far"`, `"default"`
- **说明**: 选择深度模式

#### fixed_depth_options
- **类型**: object
- **说明**: 固定深度模式的深度值配置

#### auto_depth_settings
- **min_depth**: 最小深度限制 (米)
- **max_depth**: 最大深度限制 (米)
- **real_pupil_distance**: 真实瞳孔间距 (米)
- **fallback_depth**: 自动模式失败时的默认深度 (米)

#### depth_camera_settings
- **enabled**: 是否启用深度摄像头
- **camera_index**: 深度摄像头索引
- **depth_scale**: 深度缩放因子

## 使用方法

### 方法1: 修改配置文件
1. 编辑 `depth_settings.json`
2. 修改 `depth_mode` 为所需模式
3. 重启程序

### 方法2: 代码中修改
在 `main.py` 中找到以下行并修改：
```python
depth_mode = 'auto'  # 修改为所需模式
```

## 深度模式选择建议

### 近距离使用 (0.3-0.5米)
- **场景**: 桌面使用、近距离阅读
- **推荐模式**: `"near"` 或 `"auto"`
- **配置**: `"near": 0.4`

### 中距离使用 (0.5-1.0米)
- **场景**: 正常办公、学习
- **推荐模式**: `"medium"` 或 `"auto"`
- **配置**: `"medium": 0.8`

### 远距离使用 (1.0-2.0米)
- **场景**: 大屏幕、演示
- **推荐模式**: `"far"` 或 `"auto"`
- **配置**: `"far": 1.2`

### 距离变化场景
- **场景**: 移动使用、距离不固定
- **推荐模式**: `"auto"`
- **优势**: 自动适应距离变化

## 自动深度估计原理

### 基于瞳孔间距的深度估计
```
深度 = (真实瞳孔间距 × 焦距) / 像素瞳孔间距
```

### 参数说明
- **真实瞳孔间距**: 平均6.5cm
- **焦距**: 从相机内参获取
- **像素瞳孔间距**: 从关键点检测获取

### 限制条件
- 最小深度: 0.3米
- 最大深度: 2.0米
- 超出范围时使用默认值

## 调试和监控

### 日志输出
程序会输出深度相关的日志信息：
```
动态估计深度: 0.75m
使用固定深度: 0.6m
深度估计失败，使用默认深度: 0.6m
```

### 深度值验证
可以通过日志监控深度值是否合理：
- 正常范围: 0.3-2.0米
- 异常情况: 超出范围或检测失败

## 性能优化

### 自动模式性能
- **优点**: 适应性强，精度高
- **缺点**: 计算开销稍大
- **建议**: 稳定环境可使用固定模式

### 固定模式性能
- **优点**: 计算开销小，稳定
- **缺点**: 适应性差
- **建议**: 距离变化大的场景不适用

## 故障排除

### 常见问题

1. **深度估计不准确**
   - 检查人脸检测质量
   - 调整 `real_pupil_distance` 参数
   - 检查相机内参是否正确

2. **深度值超出范围**
   - 调整 `min_depth` 和 `max_depth`
   - 检查相机位置和角度

3. **配置文件加载失败**
   - 检查文件路径和格式
   - 查看错误日志信息

### 调试步骤

1. 检查配置文件格式
2. 查看日志输出
3. 验证相机内参
4. 测试不同深度模式
