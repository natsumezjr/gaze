#### 1.1 几何一致性指标

**算法误差：**

  - 优化方向：半自动标注、在线精度评估

- **3D重建误差**：$\epsilon_{3D} = \sqrt{\sum_{i=1}^{3} (x_i^{reconstructed} - x_i^{true})^2}$

#### 2.2 误差传播模型

### 4. Kappa角补偿算法的详细调研

#### 4.1 理论基础
Kappa角是眼球光学轴与视觉轴之间的夹角，典型值范围：$4^\circ - 8^\circ$

**数学建模**：$\vec{g}_{compensated} = R(\vec{k}, \kappa) \cdot \vec{g}_{theoretical}$

其中：
- $\vec{g}_{theoretical}$：理论视线向量
- $\vec{k}$：kappa轴单位向量
- $\kappa$：kappa角（弧度）
- $R(\vec{k}, \kappa)$：绕轴旋转矩阵

旋转计算：罗德里格斯旋转公式绕轴旋转向量。

**标定流程**：客户注视c#客户端编写的固定点界面，取瞳孔中心与固定点的向量为"补偿后向量"，眼球中心与瞳孔中心的向量为"理论视线向量"，多次采样从而估计kappa轴单位向量、kappa角（弧度）获得绕轴旋转矩阵。

#### 4.2 旋转轴估算算法调研

**最小二乘估计：**
目标函数：$\min_{\vec{k}, \kappa} \sum_{i=1}^{N} |R(\vec{k}, \kappa) \vec{g}_i - \vec{g}_i^{actual}|^2$

**约束条件**：
- $|\vec{k}| = 1$（单位向量约束）
- $\kappa \in [-\frac{\pi}{6}, \frac{\pi}{6}]$（生理学约束）

**问题**：
- 与RANSAC多次采样的融合的策略？

**几何约束估计：**
**原理**：kappa轴垂直于理论视线和实际注视方向构成的平面

**算法步骤调研**：
1. 计算叉积：$\vec{c}_i = \vec{g}_i^{theoretical} \times \vec{g}_i^{actual}$
2. 归一化：$\vec{k}_i = \frac{\vec{c}_i}{|\vec{c}_i|}$
3. 聚类分析：找到最一致的kappa轴方向
4. 角度估计：基于选定轴计算kappa角

**问题**：
- 聚类算法的选择？
- 异常样本的识别？
- 多解情况的处理？

#### 4.3 标定流程设计调研

**四角标定法**：
- 左上角：$(x_{tl}, y_{tl})$
- 右上角：$(x_{tr}, y_{tr})$
- 左下角：$(x_{bl}, y_{bl})$
- 右下角：$(x_{br}, y_{br})$
