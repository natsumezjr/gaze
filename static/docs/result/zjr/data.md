## 关键说明与修正依据

1.  **瞳孔中心距离修正**：
    *   **原误差**：误将眼球半径直接作为距离，未扣除前房深度及角膜厚度。
    *   **修正公式**：`距离 = 眼球半径 - (前房深度 + 角膜厚度)`
    *   最小值：`11.5 - (3.5 + 0.55) = 7.45 mm`
    *   最大值：`12.5 - (3.0 + 0.5) = 9.0 mm`
    *   考虑光照位移 ±0.5 mm，故修正为 **7.95–8.95 mm**。
