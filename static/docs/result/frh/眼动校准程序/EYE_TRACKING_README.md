# 眼动追踪校准程序使用说明

## 功能概述

本眼动校准程序现已支持通过用户摄像头采集真实的视线输入，不再依赖模拟数据。主要功能包括：

1. **摄像头视线追踪**：使用网页摄像头实时检测用户眼睛位置和视线方向
2. **校准流程优化**：要求用户注视点在误差范围内才能继续校准
3. **数据采集**：收集校准过程中的视线数据，用于后续分析和校准
4. **后端数据交换**：预留与后端交换数据并进行kappa角补偿的接口

## 使用方法

### 1. 安装依赖

```bash
# 安装依赖包
npm install

# 下载眼动追踪所需的模型文件
npm run download-models
```

### 2. 启动程序

```bash
npm run serve
```

### 3. 使用摄像头追踪

1. 打开浏览器访问 http://localhost:3001
2. 点击「启用摄像头」按钮，授予摄像头访问权限
3. 摄像头状态显示「已启用」后，点击「开始校准」按钮
4. 按照屏幕提示，注视移动的校准点
5. 保持注视直到校准点变色并移动到下一个位置
6. 完成所有校准点后，系统会自动处理数据并显示结果

## 注意事项

1. **摄像头位置**：摄像头应正对面部，距离约50-70厘米
2. **光线条件**：确保面部光线充足均匀，避免强光直射或背光
3. **眼镜使用**：可以佩戴眼镜，但可能会影响追踪精度
4. **头部位置**：校准过程中保持头部相对稳定
5. **浏览器支持**：推荐使用最新版Chrome或Edge浏览器

## 技术实现

### 眼动追踪实现

本程序使用以下技术实现眼动追踪：

1. **TensorFlow.js**：用于运行机器学习模型
2. **face-api.js**：用于人脸检测和面部特征点提取
3. **WebRTC**：用于访问用户摄像头
4. **Canvas API**：用于图像处理和视觉反馈

### 视线估计算法

视线估计基于以下步骤：

1. 检测人脸并提取面部特征点
2. 定位眼睛位置和眼睛特征点
3. 计算眼睛方向向量
4. 估计视线在屏幕上的位置
5. 应用平滑处理减少抖动

### 校准流程

校准流程经过优化，包括以下改进：

1. **注视判断**：只有当用户视线稳定在目标点附近一定时间后才继续
2. **视线平滑**：使用历史数据平均值计算当前视线位置，减少抖动
3. **实时反馈**：显示用户当前视线位置，并根据是否在目标范围内变色

## 与后端集成

本程序预留了与后端系统集成的接口，可以：

1. 将采集到的校准数据发送到后端
2. 接收后端返回的kappa角补偿参数
3. 应用kappa角补偿修正视线位置

具体集成方式请参考代码中的`sendDataToRealBackend`函数和相关注释。

## 故障排除

1. **摄像头无法启用**：检查浏览器权限设置，确保已授予摄像头访问权限
2. **追踪不准确**：调整光线条件，确保面部光线充足均匀
3. **模型加载失败**：检查网络连接，确保模型文件已正确下载
4. **性能问题**：关闭其他标签页和应用程序，减少系统负载
